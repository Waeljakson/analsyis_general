# V11 — تقرير الطالب الموحد

- إضافة شاشة تقارير الطلاب داخل منصة السجلات.
- تجميع المواقف والإرشاد والغياب والتأخر ودراسات الحالة والتواصل والمتابعات في تقرير واحد.
- فلترة حسب الطالب والفصل والنوع والحالة والفترة الزمنية.
- عرض ملخص إحصائي وتسلسل زمني وكل تفاصيل السجلات.
- طباعة التقرير أو حفظه PDF من المتصفح.

# تحديث V3 — شريط تنقل موحد احترافي

- استبدال القوائم العائمة بشريط منصات مؤسسي ثابت أعلى الصفحة.
- إبراز المنصة الحالية، والمنصات المتاحة، وغير المفعلة، والقادمة.
- عرض اسم الباقة الحالية وحالتها وتاريخ انتهائها بصورة واضحة.
- تحسين كامل للعرض على الهاتف والتابلت مع تمرير أفقي منظم.
- إضافة زر واضح للعودة إلى بوابة المنصات.

# سجل التغييرات

## V2 — الباقات المنفصلة والباقة الشاملة
- فصل اشتراك السجلات الرقمية عن اشتراك تحليل النتائج.
- باقة السجلات: 10 ريالات شهريًا أو 50 ريالًا سنويًا.
- الباقة الشاملة: 50 ريالًا شهريًا أو 300 ريال سنويًا.
- جميع طلبات المنصات تظهر في لوحة مدير موحدة مع تحديد نوع الطلب.
- تفعيل الباقة المحددة فقط، وعدم انتقال صلاحية السجلات إلى التحاليل أو العكس.
- تحديث RLS بحيث لا يمكن حفظ أو قراءة السجلات إلا بباقة السجلات أو الباقة الشاملة.
