منصة V16 — تقارير الإنجاز

1) فك الضغط.
2) ارفع كل محتويات المجلد إلى جذر مستودع GitHub داخل main مع الاستبدال.
3) تأكد من وجود reports/index.html و messages/index.html.
4) اضغط Commit changes وانتظر نجاح Pages.
5) افتح البوابة وسجل الدخول ثم افتح تقارير الإنجاز.
6) اضغط Ctrl+F5 مرة واحدة.

تقارير الإنجاز متاحة مع أي باقة مدفوعة. مكتبة الرسائل تبقى للباقات السنوية فقط.
