# منصة تحليل النتائج التعليمية — النسخة العامة Premium

نسخة مستقلة للمدارس تعمل على GitHub Pages ومتصلة بقاعدة Supabase الحالية.

## المزايا
- صفحة تسجيل دخول مستقلة.
- حساب تجريبي: التحليل والعرض فقط.
- Premium شهري: 10 ريالات، أو سنوي: 50 ريالًا، ويتيح الحفظ والطباعة PDF وتصدير Word.
- تخصيص اسم المدرسة وشعارها.
- رموز تعبيرية أصلية ومحايدة للتحليل التعليمي والتميز، مع إمكانية رفع شعار المدرسة.
- لوحة مدير النظام لمراجعة طلبات الاشتراك وتفعيل شهر أو سنة حسب الخطة المختارة.
- تحليل من الأول الابتدائي حتى الثالث الثانوي.

## النشر
ارفع محتويات المجلد إلى GitHub Pages. لا ترفع ملفات Excel الخاصة بالطلاب.

## الاشتراك والتفعيل عبر واتساب
- الاشتراك الشهري: 10 ريالات، والسنوي: 50 ريالًا.
- لا يعرض التطبيق أي بيانات حساب بنكي.
- يختار المستخدم الخطة ثم يضغط زر مراسلة واتساب للحصول على بيانات الاشتراك.
- رقم واتساب: 00966582712620.
- بعد التواصل يعود المستخدم إلى المنصة ويضغط «إرسال طلب التفعيل».
- لن يتم التفعيل إلا بعد التواصل عبر واتساب واستكمال إجراءات الاشتراك.

## حماية المحتوى
تتضمن النسخة تعطيل النسخ والقائمة السياقية واختصارات الحفظ والطباعة للحسابات غير المصرح لها، مع علامة مائية ديناميكية وحاجب شاشة عند رصد بعض محاولات التصوير. لا يمكن لأي تطبيق ويب منع لقطات الشاشة على مستوى نظام التشغيل منعًا مطلقًا.


## ملاحظة تقنية عن لقطات الشاشة
تم تعزيز حاجب الشاشة والعلامة المائية ورصد فقدان التركيز. مع ذلك، لا تملك صفحات الويب صلاحية منع أداة القص في Windows أو تصوير الشاشة بكاميرا خارجية منعًا مطلقًا؛ الحماية المتاحة داخل المتصفح هي حماية ردعية وتقليل للتسريب وليست DRM على مستوى نظام التشغيل.


## الدعم الفني وصلاحيات المدير — V6
- شات دعم داخل الصفحة بين المستخدم وفريق الإدارة.
- صندوق وارد لمديري النظام مع الرد وإغلاق/إعادة فتح المحادثة.
- مدير النظام يستطيع تعيين أي حساب مسجل كمدير إضافي أو إلغاء صلاحية مدير آخر.
- لا يستطيع المدير إلغاء صلاحية حسابه الحالي، لمنع فقدان الوصول الإداري.


## حماية الشاشة حسب الاشتراك
- الحساب التجريبي: تظهر العلامة المائية ويعمل حاجب الشاشة عند محاولة الالتقاط أو استخدام أداة القص.
- Premium ومدير النظام: لا تظهر العلامة المائية، ولا يعمل حاجب Print Screen أو Snipping Tool.
