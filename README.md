# بوابة خدمات الموجه الطلابي — V3

منصة موحدة تضم:
- صفحة تسجيل دخول ولوحة اختيار المنصات في الجذر.
- منصة تحليل النتائج في `analysis/`.
- منصة السجلات الرقمية في `records/`.

## آلية الدخول
1. يتم تسجيل الدخول من الصفحة الرئيسية فقط.
2. بعد نجاح تسجيل الدخول تظهر لوحة المنصات دائمًا، ولا يتم فتح أي منصة تلقائيًا.
3. المنصة المشمولة في باقة المستخدم تظهر مفعّلة، والمنصة غير المشمولة تظهر غير مفعّلة.
4. الباقة الشاملة ومدير النظام يمكنهما دخول جميع المنصات المتاحة.
5. داخل كل منصة يظهر شريط تنقل يسمح بالانتقال إلى باقي المنصات المشمولة في الاشتراك.
6. محاولة فتح رابط منصة مباشرة تعيد المستخدم إلى لوحة الاختيار، حتى يختار المنصة بنفسه.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد بالكامل إلى مستودع واحد. يجب أن يظل ملف `index.html` الموجود في الجذر هو الصفحة الرئيسية للموقع.


## تحديث V3
تم تحسين شريط التنقل داخل المنصات ليظهر بصورة موحدة واحترافية، مع حالة الباقة والمنصة الحالية وحالات المنصات الأخرى.


## قواعد الترقية V4
- الطلب المطابق لاشتراك نشط يُرفض برسالة: أنت بالفعل مشترك في هذه الباقة.
- الشهرية إلى السنوية: سنة كاملة تضاف بعد تاريخ انتهاء المدة الشهرية الحالية.
- الفردية إلى الشاملة: تُمدد الباقة الفردية بنفس مدة الشاملة، فتعود بمدتها المتبقية بعد انتهاء الشاملة.
- السنوية إلى الشهرية غير متاحة حتى انتهاء الخطة السنوية.
