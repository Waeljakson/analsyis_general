# بوابة خدمات الموجه الطلابي — V5

بوابة موحدة تضم:

1. منصة تحليل النتائج التعليمية.
2. منصة السجلات الرقمية للموجه الطلابي.
3. منصة العروض التقديمية.
4. منصة أفكار البرامج — قيد التطوير.

## الباقات

- باقة منصة واحدة: 10 ريالات شهريًا أو 50 ريالًا سنويًا.
- الباقة الشاملة: 50 ريالًا شهريًا أو 300 ريال سنويًا.

تظهر للمستخدم فقط المنصات المشمولة في اشتراكه. الباقة الشاملة تفتح جميع المنصات المتاحة، ومدير النظام لديه صلاحية كاملة.

## منصة العروض

تشمل 30 برنامجًا أوليًا موزعة إلى برامج وزارية ونوعية وقيمية، مع تصفية حسب المرحلة والجمهور، وعرض الشرائح داخل المنصة فقط دون ملفات تنزيل. كما تتضمن طلب تصميم برنامج خاص عبر واتساب وتسجيل الطلب في قاعدة البيانات.

## النشر

ارفع جميع الملفات والمجلدات كما هي إلى جذر مستودع GitHub Pages، ولا تغيّر أسماء مجلدات `analysis` و`records` و`presentations`.


## تحديث العروض — V6

- جميع العروض الجاهزة داخل منصة العروض أصبحت لا تقل عن 15 شريحة.
- طلبات تصميم البرامج الخاصة تبدأ افتراضيًا من 15 شريحة، ولا يقبل النظام طلبًا أقل من ذلك.
- لا توجد أي خاصية تنزيل للعروض؛ العرض داخل المنصة فقط.


## تثبيت نوع طلاب العروض — V7

عند أول دخول يختار المستخدم نوع الطلاب: بنين أو بنات. يُحفظ الاختيار في قاعدة البيانات ويصبح النوع الوحيد المتاح للحساب. تغيير النوع متاح لمدير النظام فقط من تبويب المستخدمين والمديرين.


## V8 — الدعم الفني في جميع المنصات

- إضافة محادثة دعم موحدة إلى بوابة المنصات ومنصة العروض التقديمية، إلى جانب المحادثة الموجودة في التحاليل والسجلات.
- المحادثة نفسها تنتقل مع المستخدم بين المنصات باستخدام حسابه الموحد.
- إظهار عداد للردود الجديدة، وتحديث تلقائي، وإرسال الرسائل بالضغط على Enter.
- إخفاء الشات أثناء عرض الشرائح بملء الشاشة وأثناء الطباعة.


## V9 — بوابة منصات منظمة

تم إعادة تصميم بوابة المنصات كلوحة تحكم احترافية تفصل بين المنصات المتاحة والخدمات الإضافية، مع ملخص للحساب وشريط إجراءات موحد وقسم أسعار مختصر.


## V10 — عروض متنوعة وتفاعلية

- كل عرض يحتوي على 15 إلى 17 شريحة.
- ستة أنماط تصميم مختلفة: مسار بصري، تحدٍ تفاعلي، قصة قيمية، مهمة تعليمية، مختبر مهارات، وعرض وثائقي.
- رسوم تفاعلية داخل الشرائح تشمل الاختيارات، الاختبارات، المقاييس، العجلة، خرائط المفاهيم، المتابعة الأسبوعية، وقوائم الإنجاز.
- لا توجد خاصية تنزيل؛ المشاهدة والتفاعل داخل المنصة فقط.


## تقرير الطالب الموحد — V11

منصة السجلات تتضمن الآن تقريرًا شاملًا لكل طالب يجمع كل السجلات المرتبطة باسمه، مع ملخص إحصائي وتسلسل زمني وتفاصيل كاملة وخيار الطباعة أو الحفظ PDF.
